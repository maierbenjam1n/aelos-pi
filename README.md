# Aelos Pi

Das ist der originale Komponent der auf dem Raspberry Pi installiert werden
haette sollen. Wegen Problemen mit Verbinden des Raspberry Pis wurde die
Entwicklung hier eingestellt und auf den Prototyp fokussiert (mit Mockdaten).

Geplant waere gewesen auf dem Pi ein Bluetooth Service laufen zu lassen der mit
der Aelos App und Server kommuniziert haette. Konkret waere das in Rust mit
bluer (fuer Bluetooth) und reqwest (fuer HTTP-Requests) geplant gewesen, war
aber nicht mehr moeglich umzusetzen.
